# Maksym Martynyshyn — Portfolio

Portfolio website of Maksym Martynyshyn, Junior Full-Stack Web Developer & Cybersecurity Student.

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🛠️ Local Development

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## 📦 Deployment to Vercel

The project is connected to Vercel and deploys automatically on every push to the `main` branch.
