# Maksym Martynyshyn — Portfolio

Portfolio website of Maksym Martynyshyn, Junior Full-Stack Web Developer & Cybersecurity Student.

## 🚀 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Deployment:** [GitHub Pages](https://pages.github.com/) via GitHub Actions

## 🛠️ Local Development

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## 📦 Deployment to GitHub Pages

The project is automatically built and deployed to GitHub Pages on every push to the `main` branch via GitHub Actions workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### GitHub Pages Settings

Ensure your GitHub repository has Pages enabled via GitHub Actions:
1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **GitHub Actions**.
